4 个核心模块
01 Case 优化

继续改去哪儿、今朝和被窝

这周还是继续改前面三个 Case，主要是收信息、调顺序、改版式。现在重点已经不是把后台分析写得多全，而是这一页到底该留哪些内容，怎么让人一眼看懂这个账户在怎么投。

做 Case 这件事现在更像是在做取舍，不是知道多少就全塞进去。
02 顾家家居

新做一个顾家 Case

这周新增了顾家。先去看账号、推广计划、人群、关键词、SPU 和投放笔记，再决定 Case 里放什么。顾家跟前面的家装线索项目不太一样，所以版式可以参考，里面的内容还是得重新按它自己的业务来排。

同样是家居项目，顾家这页不能直接照今朝、被窝的逻辑套。
03 eMate 做图

实际拿公司 AI 做了一轮图

这周不少图片任务都直接拿 eMate 做了，包括局改素材、案例拼图、设计师系列图、改文案、改色、统一字号和位置这些。边做边记它容易出问题的地方，昨天又单独整理了一版作图能力评价。

简单拼图和短文字还挺快，要求越细，越容易反复改。
04 每日日报

数据还是照常每天跟

这三天日报正常拉，继续看消耗、CTR、CPC、私信开口、留资和 CPL。最近 Case 做得比较多，再看日报时也会顺手去想最近是不是动了计划、素材、人群或者搜索结构。

现在看日报不太会只停在“涨了还是跌了”，会多想一层为什么。

本周重点 Case｜顾家家居

CASE STUDY
NEW CASE / KUKA HOME

分析顾家家居投放策略

这周做顾家时，没有直接照搬前面几个家装 Case。先把账号、计划、人群、关键词和投放笔记过一遍，再决定这一页具体放什么。

实际执行链路
先看业务家具产品 / 门店咨询
再看账号官号 / KOS / 用户分享
往下看投放计划 / 人群 / 关键词
再看内容SPU / 笔记 / 产品卖点
最后做减法没必要的内容就不放

顾家跟今朝、被窝不是一回事。前面几个更多是在看家装线索怎么承接，顾家还要把产品、门店咨询、SPU 和不同账号的内容放在一起看。所以这页最后还是得按顾家自己的重点来收。

本周认知升级

KEY TAKEAWAYS
这周主要是在练一件事：已经看懂的东西，怎么收成一页。
1
改 Case 时

现在不太纠结“还有没有东西没写到”，反而会先看这一页是不是已经讲清楚了。

2
做顾家时

前面案例的版式能参考，但账户里真正要讲的东西还是得重新看，不能直接照搬。

3
用 eMate 时

真的拿它连续做几轮图以后，哪些任务省时间、哪些任务反而容易返工，已经比较有数了。

还要继续练

现在 Case 基本能做完整，但信息一多还是会看得比较久。后面想练的是先抓主线，再去找数据和素材，不要每次都先把所有东西翻完。

eMate 后面怎么用

这周踩过的问题先记下来。后面做图时尽量一开始就把尺寸、颜色、文字和改动范围说清楚，简单的交给它提效，太精细的就别硬磨。
